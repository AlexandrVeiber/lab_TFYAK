# Текстовый редактор с функциями языкового процессора

## Название и цель лабораторной работы

**Название:** Разработка текстового редактора с графическим интерфейсом

**Цель работы:** Разработать приложение – текстовый редактор, который в дальнейшем будет дополнен функциями языкового процессора. Приложение должно иметь графический интерфейс пользователя с возможностью редактирования текста, сохранения/загрузки файлов и вывода результатов работы анализатора.

## Описание проекта

Реализован полнофункциональный текстовый редактор с графическим интерфейсом, поддерживающий базовые операции редактирования текста, работу с файлами и имеющий область вывода результатов работы синтаксического анализатора. Приложение разработано в соответствии с требованиями лабораторной работы и подготовлено для дальнейшего расширения функционала языкового процессора.

**Основные возможности:**
- Создание, открытие, сохранение текстовых файлов (TXT, RTF)
- Полный набор операций редактирования (отмена/повтор, вырезание/копирование/вставка, удаление, выделение всего текста)
- Панель инструментов с иконками для быстрого доступа к основным функциям
- Область редактирования и область вывода результатов с возможностью изменения их размера
- Строка состояния с отображением позиции курсора и информации о файле
- Информационные окна с описанием грамматики, метода анализа, постановки задачи и т.д.
- Имитация работы синтаксического анализатора с выводом результатов в нижнюю область
- Переход к строке с ошибкой при двойном клике на сообщении в области вывода
- Контекстная справка и информация о программе

## Примеры работы

### Создание нового документа

<img width="284" height="147" alt="image" src="https://github.com/user-attachments/assets/df088418-ca60-4cd4-b5c5-ced26635eecc" />

1. Нажмите "Файл" → "Создать" или кнопку "Создать" на панели инструментов
2. Введите текст в области редактирования
3. При попытке закрыть программу будет предложено сохранить изменения

### Открытие файла

<img width="608" height="294" alt="image" src="https://github.com/user-attachments/assets/32efcaed-ff02-47bc-ae89-1a4a1bb7b4df" />

1. Нажмите "Файл" → "Открыть" или кнопку "Открыть"
2. Выберите файл в диалоговом окне
3. Содержимое файла загрузится в редактор

### Сохранение файла

1. Нажмите "Файл" → "Сохранить" или кнопку "Сохранить"
2. Если файл новый - укажите имя и расположение
3. Статус "Файл сохранен" в строке состояния подтвердит успешное сохранение

### Запуск анализатора

<img width="719" height="583" alt="image" src="https://github.com/user-attachments/assets/844af1dc-fd4b-49a1-9e7b-f39d34ba354f" />

1. Введите текст в области редактирования (например, "aab")
2. Нажмите "Пуск" или F5 или кнопку "Запуск" на панели инструментов
3. В области вывода появятся результаты анализа

## Ограничения и особенности реализации

### Известные ограничения текущей версии

1. **Синтаксический анализатор** - в текущей версии реализована имитация работы анализатора. Полноценный анализатор будет реализован на следующих этапах работы.

2. **Подсветка синтаксиса** - функция подсветки ключевых слов находится в разработке.

3. **Многооконный режим** - работа с несколькими файлами возможна последовательно, вкладки не реализованы.

4. **Форматы файлов** - поддерживаются только форматы TXT и RTF. Другие форматы открываются как текстовые.

5. **Регулярные выражения** - упрощенная проверка грамматики `^a+b$` используется для демонстрации.

6. **Размер файлов** - при работе с очень большими файлами (более 50 МБ) возможны задержки.

### Особенности реализации

- Приложение использует системные иконки Windows (Segoe MDL2 Assets)
- Автоматическое определение формата файла при открытии и сохранении
- Запрос на сохранение изменений при закрытии или открытии нового файла
- Динамическое обновление строки состояния при изменении позиции курсора
- Проверка на несохраненные изменения перед выходом
- Возможность изменения размеров областей с помощью разделителя
- Минимальные размеры окна: ширина 600, высота 400
