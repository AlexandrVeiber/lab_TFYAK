ПОСТАНОВКА ЗАДАЧИ

Цель лабораторной работы — разработать графический интерфейс (GUI) 
для языкового процессора.

Программа должна представлять собой приложение с текстовым редактором,
в котором пользователь может вводить исходный текст, а также получать
результат обработки (анализа) в отдельной области вывода.

Требования к программе:

1. Реализовать главное меню:
   - Файл
   - Правка
   - Текст
   - Пуск
   - Справка

2. Реализовать панель инструментов с кнопками для основных операций.

3. Реализовать две рабочие области:
   - верхняя — для ввода и редактирования текста;
   - нижняя — для вывода результата анализа.

4. Предусмотреть обработку горячих клавиш (Ctrl+Z, Ctrl+C и т.д.).

5. Обеспечить контроль несохранённых изменений при закрытии программы.

На данном этапе реализуется только графическая часть программы.
Анализатор текста будет добавлен в следующих работах.
