Вариант: цикл do-while на языке C++

G[<DW>]
<DW> ::= do { <BODY> } while ( <COND> ) ;
<BODY> ::= <ASSIGN> ; <DEC> ;
<ASSIGN> ::= <ID> = <ID> + <ID>
<DEC> ::= <ID> --
<COND> ::= <ID> <REL> <NUM>
<REL> ::= > | >= | < | <= | == | !=
<ID> ::= Б { Б | Ц | _ }
<NUM> ::= Ц { Ц }

где:
Б — буквы латинского алфавита A...Z, a...z
Ц — цифры 0...9

Пример корректной строки:
do {
    number++;
} while (number < 5);


Условные коды лексем

1  — целое без знака
2  — идентификатор
3  — ключевое слово
4  — оператор
5  — разделитель
6  — пробельный символ
99 — ошибка

Ключевые слова:
do, while

Операторы:
+, ++, -, --, >, >=, <, <=, =, ==, !, !=, *, /

Разделители:
{ } ( ) ;

Пробельные символы:
пробел, табуляция
