СПРАВКА ПО ПРОГРАММЕ GUI

Программа представляет собой специализированный текстовый редактор,
разработанный в рамках лабораторной работы по дисциплине
«Теория формальных языков и компиляторов».

Главное окно состоит из:
- главного меню;
- панели инструментов;
- области редактирования текста (верхняя часть);
- области вывода результата (нижняя часть).

====================================================
1. МЕНЮ «ФАЙЛ»
====================================================

Создать
    Очищает редактор.
    При наличии несохранённых изменений выводится диалог подтверждения.

Открыть
    Позволяет выбрать и открыть текстовый файл (.txt).

Сохранить
    Сохраняет текущий документ.
    Если файл не был сохранён ранее — вызывается «Сохранить как».

Сохранить как
    Сохраняет документ в новый файл.

Выход
    Закрывает программу.
    При наличии несохранённых изменений запрашивает подтверждение.

====================================================
2. МЕНЮ «ПРАВКА»
====================================================

Отменить (Ctrl+Z)
    Отмена последнего действия.

Повторить (Ctrl+Y)
    Повтор отменённого действия.

Вырезать (Ctrl+X)
    Перемещает выделенный фрагмент в буфер обмена.

Копировать (Ctrl+C)
    Копирует выделенный фрагмент в буфер обмена.

Вставить (Ctrl+V)
    Вставляет текст из буфера обмена.

Удалить (Del)
    Удаляет выделенный фрагмент текста.

Выделить всё (Ctrl+A)
    Выделяет весь текст в редакторе.

====================================================
3. МЕНЮ «ТЕКСТ»
====================================================

Пункты данного меню открывают окна с теоретической информацией,
которая загружается из текстовых файлов в папке Texts.

Разделы:
- Постановка задачи
- Грамматика
- Классификация грамматики
- Метод анализа
- Тестовый пример
- Список литературы
- Исходный код программы

====================================================
4. КОМАНДА «ПУСК»
====================================================

На текущем этапе реализована тестовая версия анализа.
После нажатия кнопки выполняется:

- подсчёт количества строк;
- подсчёт количества символов;
- вывод времени выполнения.

Результат выводится в нижней области окна.

====================================================
5. ПАНЕЛЬ ИНСТРУМЕНТОВ
====================================================

Кнопки на панели инструментов дублируют основные команды меню:

- Создать
- Открыть
- Сохранить
- Отменить
- Повторить
- Копировать
- Вырезать
- Вставить
- Пуск
- Справка
- О программе

====================================================
6. ОСОБЕННОСТИ ИНТЕРФЕЙСА
====================================================

- Размер окна можно изменять.
- Соотношение областей можно менять с помощью разделителя (GridSplitter).
- Полосы прокрутки появляются автоматически.
- При закрытии программы проверяется наличие несохранённых изменений.
