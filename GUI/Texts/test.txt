Тестовые примеры

1. Корректный пример
do {
    c = a + b;
    a--;
} while (c >= 0);


Ожидаемый результат:
Ошибок нет.
Должны распознаваться ключевые слова do, while, идентификаторы a, b, c,
операторы =, +, --, >=, разделители { } ( ) ; и число 0.

2. Строка с недопустимым символом
do {
    c = a @ b;
    a--;
} while (c >= 0);

Ожидаемый результат:
Символ @ должен быть определен как ошибка.
Для него должен выводиться код 99 и позиция в строке.

3. Доп. пример
do {
    sum = a1 + b2;
    a1--;
} while (sum != 10);

Ожидаемый результат:
Сканер должен корректно учитывать номер строки и позицию символов.
